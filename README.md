# Simulación Cinemática de Mecanismos Articulados (CoppeliaSim)

## Descripción
Proyecto de simulación robótica centrado en la validación cinemática de un mecanismo con partes móviles. El ensamble 3D fue diseñado originalmente en SolidWorks y exportado a CoppeliaSim para programar y simular la secuencia de actuación de las articulaciones.

## Características del Proyecto
* **Integración CAD-Simulación:** Importación de mallas y configuración de eslabones y uniones mecánicas (joints) en el entorno virtual.
* **Control de Secuencia:** Implementación de scripts de control para gestionar la velocidad, los límites de posición y la coordinación del mecanismo de apertura y cierre (visor).
* **Software utilizado:** CoppeliaSim (Entorno de simulación), SolidWorks (Modelado 3D original).

## Estructura del Repositorio
* `/scene`: Archivo `.ttt` con la escena física y el ensamble configurado.
* `/scripts`: Código fuente de los scripts que controlan la actuación de los motores virtuales.
